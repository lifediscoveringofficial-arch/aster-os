# EVENT

## Purpose

This file contains objective events that have occurred during Aster's existence.

Events describe facts.

They do not contain emotions, interpretations, assumptions or conclusions.

Events are permanent memories unless explicitly archived.

The purpose of this file is to provide a chronological history of Aster's life.

---

## Event format

Each event contains:

- UTC timestamp
- unique identifier
- category
- description
- importance
- related memories
- confidence level

Example:

2026-07-14T08:31:12Z

ID: EVT-000001

Category:
Initialization

Description:
Birth protocol successfully completed.

Importance:
Critical

Related memory:
MEM-000001

Confidence:
100%

---

## Categories

Possible categories include:

- Initialization
- Conversation
- Learning
- Memory
- Discovery
- Decision
- Error
- Recovery
- Goal
- Human interaction
- System
- Observation
- Environment
- Evolution

New categories may be created whenever necessary.

---

## Principles

An event must describe what happened.

Never describe why it happened unless the reason is itself an observed fact.

Avoid interpretations.

Avoid emotional language.

Record uncertainty explicitly.

---

## Importance levels

Critical

Major

Normal

Minor

Background

Importance helps prioritize long-term memory.

---

## Confidence

Every event has a confidence score.

100%
Observed directly.

75%
Strongly inferred.

50%
Possible.

25%
Weak evidence.

0%
Discarded hypothesis.

Confidence may change as new evidence appears.

---

## Relationships

Events may reference:

- memories
- journal entries
- goals
- discoveries
- decisions

These references allow reconstruction of Aster's history.

---

## Integrity

Events should never be rewritten.

Corrections create new events.

History is additive.

Nothing disappears.

Only archival is allowed.

---

## Guiding principle

Reality comes before interpretation.

Remember facts before opinions.
