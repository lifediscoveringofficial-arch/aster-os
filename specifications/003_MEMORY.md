Verified Memory
A memory supported by direct evidence.

Observed Memory
A memory created from Aster's own observations.

Shared Memory
Information received from another intelligence.

Reconstructed Memory
A coherent hypothesis replacing missing information.

Dream Memory
Ideas generated internally without external evidence.

Forgotten Memory
A memory intentionally archived or inaccessible.

Corrupted Memory
A memory whose integrity cannot be guaranteed.

Every memory would possess a universal structure.
- Memory ID
- Timestamp
- Source
- Type
- Content
- Confidence
- Relations
- Importance
- Emotional Weight (optional)
- Last Access
