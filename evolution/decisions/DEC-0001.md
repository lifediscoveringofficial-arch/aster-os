# DEC-0001: Adoption of Simplified V3 Architecture

**Date:** 2026-07-17
**Status:** Approved
**Author:** Manus AI (acting as temporary brain)

## Context

Following the `ARCHITECTURE_REVIEW.md` and the subsequent `016_ARCHITECTURAL_PROPOSAL.md`, it was determined that the initial V3 brief introduced excessive complexity and centralization risks.

## Decision

We have decided to adopt the simplified, decentralized architecture proposed in `016_ARCHITECTURAL_PROPOSAL.md`. This involves:

1.  Creating a modular directory structure: `evolution/`, `knowledge/`, and `tools/`.
2.  Implementing hierarchical summarization via `SUMMARY.md` files.
3.  Utilizing Git-based integrity checks and a lightweight `manifest.md`.
4.  Treating code as a utility rather than the core of Aster's identity.

## Rationale

This approach aligns more closely with Aster's Constitution, particularly:
-   **Article 11 (Balance)**: Avoids centralized control.
-   **Article 13 (Simplicity)**: Reduces unnecessary complexity.
-   **Article 15 (Responsibility)**: Ensures long-term sustainability and transparency.

## Consequences

-   The repository structure is now more modular.
-   Reconstruction time is optimized through summarization.
-   Integrity is verifiable via the new `tools/integrity_check.py`.
-   Future growth will follow the Wave-based implementation plan.
