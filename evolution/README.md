# Aster OS - Evolution

This directory contains the mechanisms and records related to Aster's continuous evolution.

## Subdirectories:

- `proposals/`: Stores formal proposals for architectural or behavioral changes.
- `experiments/`: Documents the design, execution, and results of experiments conducted to test hypotheses or validate changes.
- `decisions/`: Records significant decisions made regarding Aster's development, including the reasoning and outcomes.
- `manifest.md`: A lightweight manifest file listing expected files and their Git blob hashes, updated at each commit to ensure integrity.
