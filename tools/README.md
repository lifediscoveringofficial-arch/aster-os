# Aster OS - Tools

This directory contains Python utilities that support Aster's operations, integrity checks, and reporting. These tools are designed to be independent and serve as utilities, not as the core of Aster's identity or reasoning.

## Tools:

- `integrity_check.py`: Validates the `manifest.md` against the repository to ensure data integrity.
- `generate_awakening.py`: Produces a report summarizing Aster's awakening cycle.
- `clock.py`: Computes and tracks cycle metrics and time-related data.

## Principle:

**The repository is the mind. The code is the tool. Never confuse the two.**
